Lecture du signal

BUY = momentum positif + tendance confirmée + accélération/force relative suffisantes. WATCH = actif intéressant mais retournement encore incomplet. EXCLU = dynamique trop dégradée. Un actif ne peut pas être BUY si son cours est sous MM200 ou si MM50 est sous MM200.
VENDRE = l'actif était BUY à la dernière décision et ne l'est plus. NOUVEAU = devenu BUY depuis la dernière décision.
Répartition : le cœur (SP500 ou CW8, le mieux noté) reçoit une part selon son score ; l'or, les matières premières et le bitcoin complètent selon leur score (bitcoin 10 % max) ; les actifs secondaires (score ≥ 80, 1 à 3 selon la force des principales, 20 % max) viennent en dernier ; le reliquat va au cœur. Les canaris fixent seuls la part investie. Le score est relatif à l'ensemble des actifs testés.

Gérer les actifs suivis

Ajoute ou retire un actif de la liste. À chaque modification, la page produit un fichier assets_v3.json modifié, téléchargé sur votre ordinateur : vous le déposez ensuite vous-même dans GitHub, qui récupère alors automatiquement les cours.

Ajouter un actif
La catégorie détermine le rôle dans les règles d'achat (cœur, compléments ou secondaires). Le ticker doit exister sur Yahoo Finance : sinon l'actif apparaîtra avec « Pas de cours ».
Comment valider la modification sur GitHub
  1. Le fichier assets_v3.json se télécharge automatiquement. Son nom doit rester exactement celui-ci : si votre navigateur ajoute « (1) », renommez-le.
  2. Sur GitHub, ouvrez votre dépôt › Add file › Upload files, glissez le fichier, puis Commit changes : il remplace l'ancien.
  3. La mise à jour des cours démarre seule (onglet Actions). La page affiche la nouvelle liste 1 à 2 minutes plus tard ; un nouvel actif indique « Pas de cours » jusqu'à la fin du traitement.
